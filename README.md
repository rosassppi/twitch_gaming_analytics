# 🎮 Twitch Gaming Analytics

Projeto de análise de dados do mercado de streaming de games na Twitch (2016-2024).

## Sobre o projeto
Esse é meu primeiro projeto de dados, feito enquanto estudo SQL e Python.
A ideia foi usar um tema que gosto — games e streaming — para praticar de forma real.

## Ferramentas usadas
- SQL Server
- Python (pandas, matplotlib)

## O que foi analisado
- Top 5 jogos mais assistidos ao longo dos anos
- Impacto da pandemia na Twitch em 2020
- Jogos que mais cresceram entre 2020 e 2022
- Quais jogos ficaram mais tempo no Top 5
